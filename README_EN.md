## ⭐ Featured Projects

### 🧪 SampleSize_R · Clinical Trial Sample Size Calculator

**Clinical Trials · R Shiny · Statistical Computing**

Independently developed a bilingual clinical-research sample-size application in R Shiny. The current project implements **32 sample-size / precision methods** across means, proportions, survival outcomes, correlation, regression, categorical outcomes, precision analysis and crossover designs, with dynamic parameter panels, dropout adjustment, interactive power / precision curves and an extensible method registry.

- [Live Demo](https://cathy-chenyx.shinyapps.io/SampleSize_R/)
- Source code is maintained privately; the public deliverable is the working application.

### 🩺 STEMI In-hospital Bleeding Prediction

**Clinical Prediction · Real-world Data · R + Python · Machine Learning**

Developed an interpretable prediction workflow for in-hospital gastrointestinal bleeding using real-world STEMI data. The pipeline combines missing-data handling, Knockoff / Lasso variable selection, regression and machine-learning model comparison, SHAP interpretation, calibration, DeLong testing and decision-curve analysis. The final approach documented in the repository achieved a test AUC of **0.7977**.

- [GitHub Repository](https://github.com/Cathy-chenyx/STEMI_Predictive_model)

### 🌏 Gastrointestinal Cancer GBD Analysis

**Epidemiology · Global Burden of Disease · R**

Analyzed the burden and long-term trends of major gastrointestinal cancers using GBD data, including preprocessing, age-standardized measures, EAPC, SDI comparisons, age / regional subgroup analyses, global mapping and exploratory time-series forecasting.

- [GitHub Repository](https://github.com/Cathy-chenyx/gastrointestinal_cancer_GBD)
- [Supporting Report](03项目证明/统计建模_GBD疾病负担分析.pdf)
