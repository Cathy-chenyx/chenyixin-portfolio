**R · Python · Clinical Prediction · Machine Learning**

### 🌏 Gastrointestinal Cancer GBD Analysis
Epidemiologic analysis of disease burden and long-term trends across major gastrointestinal cancers using GBD data, including age-standardized measures, EAPC, SDI comparisons, subgroup analyses, global mapping, and exploratory forecasting.

**R · Epidemiology · Global Burden of Disease**  
[View repository](https://github.com/Cathy-chenyx/gastrointestinal_cancer_GBD)

**R Shiny · Clinical Trials · Statistical Computing**
